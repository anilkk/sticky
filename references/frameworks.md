# Frameworks and when to use each

Summaries in the skill's own words. Read the books for the full method.

| Need | Framework | Source |
| --- | --- | --- |
| Decide who you are for and why you win | Five components: competitive alternatives, unique attributes, value, best-fit customers, market category | April Dunford, *Obviously Awesome* |
| Turn positioning into a pitch | Insight, alternatives, value themes with proof, objections | April Dunford, *Sales Pitch* |
| Write the core messaging | Value proposition, three benefits, features as proof (VBF); A+ customer; BBQ test | Emma Stratton, *Make It Punchy* |
| Tell the narrative | Shift, Villain, Dream, Solution | Emma Stratton, *Make It Punchy* |
| Give the message a point of view | Umbrella opinion; awareness and sophistication levels | Alex James, *Message Matters Most* |
| Match the message to the reader's stage | Five awareness levels | Eugene Schwartz, *Breakthrough Advertising* |
| Make the homepage clear | Clarity before differentiation; capability, use case, and outcome per stakeholder | Fletch PMM (Pierri, Kaminski) |
| Sell on value | Before, negative consequences, after, positive business outcomes, required capabilities, proof | Force Management, *Command of the Message* |
| Learn what customers actually think | Ask about past behavior, not opinions about the future | Rob Fitzpatrick, *The Mom Test* |
| Describe the customer's progress | Job, desired outcomes, struggling moments | Ulwick and Christensen, Jobs to be Done |

## How they fit together

```txt
Research        Mom Test, JTBD            what customers did and said
Positioning     Dunford                   who, versus what, and why we win
Point of view   Alex James, Schwartz      what we believe and where the buyer is
Messaging       Stratton                  one value prop, three benefits, proof
Surfaces        Fletch, Dunford Pitch     hero, homepage, deck
Selling         Command of the Message    before, after, proof, per stakeholder
```

When a request skips a level, check the level above. A homepage that keeps changing usually has
a positioning problem, not a copy problem.

## Disagreements to know about

- **Category creation.** Dunford treats a new category as the hardest and most expensive style;
  most companies should win an existing category or a subsegment. Default to that.
- **Opinion first or clarity first.** Alex James leads with a belief; Fletch leads with what the
  product is. On a homepage hero, clarity wins. In a launch post or keynote, the opinion can lead.
- **Features on the hero.** Fletch often shows capability in the headline for technical buyers;
  Stratton puts value first. For developer audiences, capability plus outcome usually works best.
